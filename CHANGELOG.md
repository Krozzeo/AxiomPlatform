# Changelog

## 0.1.3 / P4 — 2026-10-21 (review candidate)

Redesigned English Hub with one project/session table and icon actions. Separate Settings pages, shared GitHub/AI account icons, disconnected import gate, light/dark/system appearance, keyboard support and Axiom identity. Added rename, catalog removal and reviewed permanent deletion. Native picker has an owned foreground dialog, cancellation and bounded timeout. Relocatable Windows startup verifies/downloads missing runtimes, installs locked dependencies, opens the browser and retains startup errors. Product installations support compatibility validation, deferred activation and rollback. Game Engine hosted project creation restores its 3D starter scene. Earlier P2/P3 branches and remote CI issues remain separate integration gates.

## 0.1.2 / P3 — 2026-10-21 (review candidate)

Shared provider/turn runtime, cancellation/usage, session credential broker, registry/validator, journal and human diff/review gates. Context, game tools and application transaction remain in Engine. P2 is not integrated by this delivery; real-model evaluation and #55 remain separate.

## 0.1.1 / P2 — 2026-10-21 (review candidate)

Persistent catalog/settings, folder selection/import and session GitHub transport/account with isolated project destinations. HTTPS pinned provider with integrity; selective adoption of native preferences. P1 accepted by the user and integrated after CI.

## 0.1.0 / P1 — 2026-10-21

Local Hub/host, executable descriptor/IPC, revision-aware sessions/save/close, bounded paths and diagnostics. Independent real Engine adapter without format migration or GitHub/AI extraction. Joint and Null browser acceptance; subsequently integrated after CI and manual acceptance.

## P0 — 2026-10-21

Master plan, ownership, preliminary contracts, sessions/AI/compatibility/migration/validation and P0–P5 roadmap. Public MIT by owner decision. No executable extraction in P0.
