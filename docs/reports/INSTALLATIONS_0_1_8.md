Implements installed-only product tabs; auto-refreshing stable/experimental downloads with independent same-version commit identity; explicit experimental activation; reviewed native recycling of individual versions; persistent/resettable per-product GitHub source URLs; and the portable Axiom Hub Windows shortcut with logo.

Local unit and real-product browser acceptance is recorded in the delivery. Controlled fixtures prove UI/transactions and preserve a real open Engine project. The shortcut is exercised after relocation while the original launcher still exists. Exact-head CI and actual public publication/download are separate gates; no main merge or stable release is implied by local completion. Shared accounts, API0.1/protocol1, scripting SDK8/native formats1 and Engine M19–M40 scope stay unchanged.
